<b>Wiki Description: </b>The Decryptor is a Crewmate Investigative role that can complete tasks to slowly reveal the letters in players' original roles. If settings allow, evils may be alerted of the Decryptor's presence. The Decryptor only decrypts the roles players spawned into the game with, not necessarily what they currently are.

<b>Options: </b>

- Number Of Tasks For Letter Reveal
- Alert Evils Of Decryptor
- Number Of Letters Revealed For Evil Alert
