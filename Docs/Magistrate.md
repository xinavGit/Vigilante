<b>Wiki Description: </b>The Magistrate is a Crewmate Power role that can recruit a player every round to be a Juror. The Magistrate can then bring judgement to any player in the meeting except the Juror. If the player is an enemy of the Juror, they will die. If they are an ally of the Juror, the Magistrate will die.

<b>Options: </b>

- Max Judgements
- Get More Judgement Uses From Tasks
- Tasks Per Ability Use (i actually think this might be broken rn.....)
- Enlist Cooldown
- Enlist Delay (Can Cancel like monarch)
- Notify Juror On Enlistment
